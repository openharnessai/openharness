# Changelog

## [0.1.0] - 2026-10-05

### Added

- `harness.js` CLI: `list`, `search`, `show`, `validate`, `table`, `help`, with `--json` output.
- 44-harness directory in `data/harnesses.json`.
- Unified Harness Protocol (UHP) harness-card schema in `docs/schema.json`.
- Dependency-free smoke tests in `test.js`.
- GitHub Actions CI in `.github/workflows/ci.yml`.
