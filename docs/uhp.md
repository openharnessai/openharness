# Unified Harness Protocol (UHP)

The Unified Harness Protocol is a lightweight, open vocabulary for describing what an agent harness provides and how it is verified.

## Fields

| Field | Description |
|-------|-------------|
| `capabilities` | What the harness can do (tools, sandbox, memory, permissions) |
| `verification` | How those capabilities are evidenced (benchmarks, reviews, usage) |
| `availability` | Current deployment status and access model |

## Why

A common vocabulary makes harnesses comparable across frameworks — the same way a model card describes a model, a harness card describes a harness.
